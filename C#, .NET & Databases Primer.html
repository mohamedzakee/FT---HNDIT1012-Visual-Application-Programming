Three rules to remember

  • C# is case-sensitive: Main and main are different names.
  • Every statement ends with a semicolon ;
  • Curly braces { } group code into blocks, and every { needs a matching }.

Naming rules

Start with a letter or _. Letters, digits and _ only, no spaces. You cannot use a keyword such as class or int. Convention: camelCase for variables (totalMarks), PascalCase for classes and methods (CalculateTotal).

How .NET runs your code

Your C# is compiled twice: first to CIL when you build, then to machine code by the JIT compiler when the program runs. Press Build, then Run.

.NET Framework or .NET?

.NET Framework 4.8 is the Windows-only version used in this module for Windows Forms. .NET (versions 8, 10 and later) is the newer cross-platform version that also runs on Linux and macOS. Both use the same idea: C# → CIL → CLR + JIT → machine code.
